# Plugin icon

`github.png` is the GitHub dark icon from
[Skill Icons](https://github.com/tandpfun/skill-icons), rendered as a 256 x 256
PNG without changes to its design.

- Source: [`icons/Github-Dark.svg`](https://github.com/tandpfun/skill-icons/blob/7f7e691e71aec64e8354bf697835e009d1ad80f8/icons/Github-Dark.svg)
- Revision: `7f7e691e71aec64e8354bf697835e009d1ad80f8`
- License: MIT; see `LICENSE-skill-icons.txt`.

The fixed dark background and white mark keep the icon readable without
depending on the application's text color.
